⚡ Plugin TypeScript Simple

Utilisation du ClippyPlugin sans framework

1️⃣ Chargement basique

Charge Clippy et le fait parler

const plugin = new ClippyPlugin();
await plugin.load('Clippy');
await plugin.show();
await plugin.speak('Hello!');

2️⃣ Auto-load avec config

Charge automatiquement avec message de bienvenue

const plugin = new ClippyPlugin({
  autoLoad: 'Merlin',
  autoShow: true,
  welcomeMessage: 'Bienvenue!'
});

3️⃣ Animations multiples

Enchaîne plusieurs actions

await plugin.speak('Je vais bouger!');
await plugin.moveTo(300, 300);
await plugin.animate();
await plugin.speak('Tada! 🎉');

4️⃣ Tips automatiques

Affiche des tips toutes les 10 secondes

const tips = [
  'Sauvegardez votre travail!',
  'Prenez une pause!',
  'Buvez de l\'eau!'
];

const timerId = plugin.startRandomTips(tips, 10000);

5️⃣ Toutes les animations

Obtenir et jouer toutes les animations

const animations = plugin.getAnimations();
console.log(animations);
await plugin.play('Congratulate');
